موقع التشفير وفك التشفير (Caesar) + حساب Hash

استخدم القسم الأول لـ Caesar، والقسم الثاني لـ Hash (SHA-256 / SHA-512).

1) Caesar Cipher

يشفّر حروف الإنجليزي (A-Z / a-z) والأرقام (0-9). يبقى أي رمز/مسافة كما هي.

فك التشفير يتم بالاتجاه العكسي لنفس قيمة الـ Shift.

2) Hash (SHA)

الـ Hash أحادي الاتجاه: لا يوجد "فك تشفير". تقدر فقط تقارن الهاش الناتج.

كل مرة تدخل نفس النص وبنفس الخوارزمية راح يطلع نفس الهاش.
